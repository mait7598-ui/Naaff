# Data Budget

تطبيق Android كيقسم رصيد الأنترنت على عدد الأيام، وكل 3 أيام كيقارن استهلاكك الحقيقي بالمفروض:

- استهلاك أكتر من المفروض: إشعار تحذير باش تنقص.
- استهلاك أقل من المفروض بـ 2GB أو أكثر: إشعار باش تزيد.

الاستهلاك كيتقرا من الهاتف (`NetworkStatsManager`) بلا ربط مع Max it.

## كيفاش تحصل على التطبيق
1. حط المشروع فـ GitHub.
2. من تبويب **Actions** دير Run لـ **Build APK**.
3. نزل `DataBudget-apk` وثبت `app-debug.apk`.

## أول استعمال
1. دخل الرصيد (مثلا 30) والأيام (30) وضغط **بدا / حفظ**.
2. ضغط **عطي إذن الوصول للاستخدام** وفعل التطبيق.
3. Xiaomi: فعل **Autostart** وخلي البطارية **No restrictions**.

الإعدادات (كل كم يوم، فرق 2GB...) فـ `Budget.kt` فوق.
